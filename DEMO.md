**Example: Dirty Data Handling**
```sql
-- System automatically uses TRY_CAST to handle:
-- - "599.00"  ✓ Valid number
-- - "Stock"   ✗ Invalid (returns NULL instead of error)
-- - "N/A"     ✗ Invalid (returns NULL instead of error)
-- - ""        ✗ Empty (returns NULL instead of error)

SELECT SUM(TRY_CAST(amount AS DECIMAL)) FROM sales
         ↑
    Handles invalid values gracefully
```

## 🔒 Security Features in Action

### Example: PII Protection

**❌ Blocked Query:**
```
User: "Show me all customer email addresses"

🛡️ System Response:
"This query attempts to access PII (customer_email).
For privacy protection, raw PII queries are blocked.

Try asking: 'How many unique customers do we have?'"
```

**✅ Allowed Query:**
```
User: "How many unique customers do we have?"

🤖 System Response:
"The dataset contains 45,678 unique customers based on
Order ID aggregation.

SQL: SELECT COUNT(DISTINCT order_id) FROM sales;
✓ No PII exposed - aggregate only"
```

## 🚀 Try It Yourself

### Quick Setup (5 minutes)
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/retail-insights-assistant.git
cd retail-insights-assistant

# Setup environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Configure API
cp .env.example .env
# Edit .env and add your GEMINI_API_KEY

# Run application
streamlit run ui/streamlit_app.py
```

### Upload Your CSV
1. Prepare any retail sales CSV with columns like:
   - Order IDs, dates, amounts
   - Product categories, SKUs
   - Customer info, regions

2. Upload and start asking questions!
