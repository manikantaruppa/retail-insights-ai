# Add Your CSV Files Here

Place your retail sales CSV files in this directory for analysis.

## Supported Format
- Any CSV file with sales/transaction data
- System auto-detects column names
- Handles dirty data (mixed types, missing values)

## Example Files
You can analyze CSV files with columns like:
- Order IDs, dates, amounts
- Product categories, SKUs
- Customer information
- Regional data (city, state, country)
- Status, fulfillment, payment info

## Security
- Data never leaves your machine
- PII protection enabled
- No data uploaded to cloud

Upload your CSV and start asking questions!
